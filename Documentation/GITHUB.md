# Публикация на GitHub

Публичного репозитория этой версии пока нет. В текущей сессии подключение GitHub не установлено.

1. Войдите в свой GitHub и создайте репозиторий `backstage`, выберите **Public**.
2. Через GitHub Desktop добавьте папку Backstage как локальный репозиторий и опубликуйте его. Публичность нужно проверить отдельно.
3. В корне репозитория должны лежать Assets, Packages, ProjectSettings, README.md, Tests и .github. Не загружайте Library, Temp или Builds.
4. Проверьте вкладку Actions: подготовленный workflow запускает проверки логики. Результата этих запусков сейчас ещё нет.
5. Откройте ссылку в приватном окне браузера. Скачайте Code → Download ZIP, распакуйте в новую папку и откройте проект.
6. После ручной проверки можно создать Release и приложить полные архивы Windows/macOS сборок.

Не публикуйте токены, пароли, лицензию Unity или папку пользовательских настроек. .gitignore уже подготовлен.
