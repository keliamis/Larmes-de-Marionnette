Backstage 2.1 — проверки изменённой версии

Статус: НЕ ЗАПУЩЕНЫ (в среде нет .NET SDK или Unity Editor).
В Tests/Program.cs добавлены проверки поздних тяжёлых врагов и лимита конфет; существующая проверка прохождения ожидает 3 волны вместо 2.

Запуск на ПК разработчика:
  dotnet run --project Tests/Backstage.Checks.csproj --configuration Release

Отдельно требуется в Unity Play Mode проверить сюжет, комикс, физику, спавн и LAN-дуэль. Предыдущий файл TEST-RESULTS.txt относится к 2.0 и НЕ доказывает тесты этой версии.
